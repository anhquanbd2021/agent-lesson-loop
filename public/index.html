Lesson Loop Lab

One toy agent, one task it cannot do, and a prompt file it is allowed to write to. What happens next depends entirely on what gets written — and whether it survives the run.

How the lab works →

The setup

The task: move one record fetch → transform → store. The hidden rule: store rejects any record that was never validated. The naive plan skips validation, so run 1 fails every time — the interesting part is what the agent does about it.
